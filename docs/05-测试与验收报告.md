# 测试与验收报告 —— 产品质量追踪系统

本文档记录“基于 SpringBoot 的产品质量追踪系统”的测试范围、测试方法、关键测试用例和验收结论。验收日期为 2026-07-07。

## 1. 测试目标

本项目测试目标不是只验证页面能打开，而是验证系统能围绕“供应商 -> 原材料批次 -> 生产工单 -> 半成品 / 成品批次 -> 客户”的质量追踪链路形成真实业务闭环。

重点验证内容：

- 前后端能正常构建和启动。
- 登录认证、角色权限和菜单过滤有效。
- 主数据、批次、生产、检验、缺陷、出货、追溯、召回、统计报表功能可用。
- 关键业务规则由后端校验，不依赖前端单侧判断。
- 生产领料、出货、召回等写操作具备事务一致性。
- 批次追溯链路完整，能支持反向追溯和正向追溯。
- 页面路由、弹窗、抽屉、图表和关键交互无明显运行时错误。

## 3. 测试数据准备

测试前使用项目内置 SQL 初始化数据库：

```powershell
mysql -uroot -p < sql/01-schema.sql
mysql -uroot -p < sql/02-init-data.sql
```

或执行：

```powershell
.\scripts\reset-db.ps1
```

内置数据包含：

- 5 个演示账号，对应管理员、仓库、生产、质检、质量主管。

- 生产工单、领料消耗、工序记录、IQC/IPQC/FQC 检验任务。
- 缺陷记录、出货记录、召回单和召回明细。
- 一条完整召回故事线：问题温控器批次 `RM-20260610-001` 影响成品批次 `FP-20260614-001` 和 `FP-20260620-001`。
